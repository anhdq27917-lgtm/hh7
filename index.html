Dự án hiện tại là một website tĩnh cơ bản bao gồm HTML, CSS và JavaScript. Điều này rất phù hợp với Cloudflare Pages vì bạn không cần chuẩn bị build environment phức tạp. Chỉ cần push code lên GitHub và nhập repo trong Cloudflare.

Triển khai

Cách setup trên Cloudflare Pages

  1. Vào Cloudflare Dashboard → Pages → Create project.
  2. Chọn GitHub và kết nối repo anhdq27917-lgtm/hh7.
  3. Để trống Build command.
  4. Output directory để mặc định là . hoặc root folder.
  5. Deploy và kiểm tra website.
